REST API discovery

REST API позволяет интегрировать мониторинг сети с внутренними порталами, автоматизацией и операционными скриптами.

Основные группы методов

ГруппаПримеры задач
УстройстваСписок, состояние, метрики и история.
ТревогиАктивные и исторические записи, комментарии, закрытие.
ОчередиЗадания, воркеры, ошибки и состояние очередей.
ПрофилиПрофили, подсети и конфигурации обнаружения.

Аутентификация и права

Защищённые маршруты требуют действующую сессию. Доступ ограничивается ролью и доменом: чтение и запись разделены, административные маршруты требуют административного права.

Ошибки

401 — нет сессии, 403 — недостаток прав или ограничение лицензии, 404 — неизвестный ресурс, 400 — ошибка входных данных.

Полный справочник маршрутов и схем тел запросов доступен в исходной документации.
