Установка discovery

Установите систему мониторинга сети на сервер провайдера, тестовый стенд или локальную машину.

Пакет Debian/Ubuntu или Fedora/RHEL

Для Debian и Ubuntu используйте .deb, для Fedora, RHEL и CentOS Stream — .rpm. Пакет создаёт системного пользователя, каталог данных и сервис systemd. Конфигурация находится в /etc/discovery-agent/config.toml, данные — в /var/lib/discovery-agent/. Перед первым запуском задайте DISCOVERY_BOOTSTRAP_ADMIN_PASSWORD длиной не менее восьми символов.

Docker

Скопируйте файл окружения, задайте секретный ключ и пароль администратора, затем выполните docker compose up -d --build. Дашборд откроется на порту 8088, внешняя база данных не обязательна.

Готовый бинарник

Для macOS, Windows и Linux доступны готовые архивы. Распакуйте архив, создайте каталог data, задайте DISCOVERY_SECRET_KEY и откройте http://localhost:8088.

Первое устройство

  1. Создайте профиль с OID sysDescr и sysUpTime.
  2. Укажите подсеть, SNMP-версию и read-community.
  3. Запустите сканирование и проверьте значения метрик.

Полные инструкции доступны в документации продукта.
